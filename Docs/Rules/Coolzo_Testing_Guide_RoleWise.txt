  Super Admin has unrestricted access to ALL modules, ALL data, ALL branches,
  and ALL configuration across the entire Coolzo platform. This is the highest
  privilege role. Changes made by Super Admin affect every other user.

PLATFORMS TO TEST ON:

  - Admin Flutter App (secondary)

PRE-CONDITION:
  - Master Data (Section B) must be complete before testing other modules.
  - Super Admin is the one who SETS UP master data.

SECTION E — WHAT TO LOG AS A BUG / DEFECT
================================================================================

USE THIS AS A REFERENCE WHEN DECIDING IF SOMETHING IS A BUG OR EXPECTED BEHAVIOR.

DEFINITELY LOG AS BUG:
  [ ] A role can see data that belongs to another role or another branch.
  [ ] A role can perform an action their permission matrix does not allow.
  [ ] A mandatory field accepts blank submission.
  [ ] An auto-generated notification is NOT sent when it should be.
  [ ] Invoice amount is calculated incorrectly (wrong tax or wrong total).
  [ ] SR status does not update when technician updates the job in the mobile app.
  [ ] GPS check-in accepts location that is clearly outside the 150-meter radius
      without showing a warning dialog.
  [ ] A job report can be submitted without 2 photos.
  [ ] Audit log is missing an entry for a completed action.
  [ ] A deleted/cancelled entity can be reactivated without proper flow.
  [ ] Soft-deleted records appear in normal list views.
  [ ] Payment amount does not match the invoice total.
  [ ] A deactivated user can still log in.
  [ ] A Super Admin cannot access another branch's data (should be able to).
  [ ] Booking wizard allows submission without T&C checkbox checked.
  [ ] Email or WhatsApp template shows merge tags as literal text (not replaced).
  [ ] An expired coupon is accepted during booking.

EXPECTED BEHAVIOR (NOT A BUG):
  [ ] Technician cannot see other technicians' jobs — this is correct.
  [ ] Finance Manager cannot see the Live Job Map — this is correct.
  [ ] Guest cannot access customer portal screens — this is correct.
  [ ] Billing Executive cannot see financial P&L — this is correct.
  [ ] Discount above threshold requires Finance Manager approval — this is correct.
  [ ] Technician cannot submit job report with incomplete mandatory checklist — correct.
  [ ] Operations Executive cannot delete job status configurations — this is correct.
  [ ] Marketing Manager cannot access customer personal data — this is correct.
  [ ] Audit log entries cannot be deleted — this is correct (append-only by design).
  [ ] Booking wizard Step 4 today's slots are hidden if less than 4 hours remain — correct.
